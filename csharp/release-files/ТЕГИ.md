# Теги репозитория для поиска

Набор подобран так, чтобы проект находили и по назначению (подсветка,
амбилайт), и по конкретным устройствам, и по технической начинке (C#, WPF,
захват экрана). Английские теги нужны для международного поиска, русские —
для поиска на русском.

## Верхние теги GitHub (Topics)

Вставляются в настройках репозитория: **Settings → General → Topics**, или
одной командой:

```bash
gh repo edit --add-topic ambilight,ambient-lighting,bias-lighting,screen-sync,tv-backlight,led-strip,addressable-leds,rgb,home-automation,dotnet,wpf,csharp,windows,tuya,wled,philips-hue,bluetooth-le,smart-home,desktop-duplication,color-effects
```

| Тег | Почему |
|---|---|
| `ambilight` | основное назначение, самый частый запрос |
| `ambient-lighting` | то же на английском, иначе формулируют |
| `bias-lighting` | профессиональное название приёма |
| `screen-sync` | подсветка синхронно с экраном |
| `tv-backlight` | так ищут подсветку за телевизором и монитором |
| `led-strip` | общий запрос по лентам |
| `addressable-leds` | адресные ленты, частый запрос у самосборщиков |
| `rgb` | общий цветовой запрос |
| `home-automation` | умный дом |
| `dotnet` | платформа |
| `wpf` | интерфейс |
| `csharp` | язык |
| `windows` | платформа |
| `tuya` | поддерживаемое устройство |
| `wled` | поддерживаемое устройство |
| `philips-hue` | поддерживаемое устройство |
| `bluetooth-le` | поддержка Bluetooth-лент |
| `smart-home` | общая категория |
| `desktop-duplication` | техническая начинка захвата |
| `color-effects` | режимы музыки и вспышек |

## Теги выпуска (Git tag)

| Тег | Что значит |
|---|---|
| `v1.0.0` | первый выпуск |

Схема нумерации — **семантическое версионирование**: `vОСНОВНАЯ.ФУНКЦИЯ.ИСПРАВЛЕНИЕ`.

- `v1.0.1` — исправления без новой функциональности;
- `v1.1.0` — новая функциональность;
- `v2.0.0` — несовместимые изменения.

## Как переименовать репозиторий позже

Если название `bluetooth-led-light` не подойдёт, его можно сменить в
**Settings → General → Repository name**. GitHub сам настроит перенаправление
со старого адреса, поэтому ссылки не сломаются.
